Build compliant container images

ImageFoundry is a container image builder with built-in OPA policy enforcement, multi-architecture support, security scanning, and an integrated CI/CD pipeline.

Get Started View on GitHub

Everything you need to ship secure images

From templating to enforcement, ImageFoundry covers the full lifecycle.

📋

OPA Policy Enforcement

Evaluate container images against Rego policies at build time. Enforce non-root users, required labels, no secrets in env, and more.

🐳

Multi-Architecture

Build for amd64, arm64, and arm/v7 from a single configuration. Native Docker Buildx integration with parallel builds.

🔒

Security Scanning

Integrated Trivy vulnerability scanning, CodeQL analysis, SAST (Semgrep, Gosec), and dependency auditing.

📄

SBOM & Signing

Automatic Software Bill of Materials generation (SPDX, CycloneDX) with Cosign keyless signing and attestation.

🧩

Template System

Declarative YAML configuration with Jinja-style Dockerfile templates. Tool layers for Go, Node.js, Python, kubectl, Helm, and more.

⚡

CI/CD Native

GitHub Actions workflows with selective builds, parallel matrices, performance testing, and Slack notifications out of the box.

Install in seconds

Choose your platform.

Go install

go install github.com/simonbbbb/imagefoundry/cmd/foundry@latest

Homebrew

brew install simonbbbb/tap/imagefoundry

Docker

docker pull ghcr.io/simonbbbb/imagefoundry:latest

Build from source

git clone https://github.com/simonbbbb/imagefoundry.git
cd imagefoundry && make build

Quick start

Four commands to go from empty to a compliant, scanned image.

$ foundry init
  → Project initialized
$ foundry validate
  → Configuration is valid
$ foundry build
  → Building container images...
$ foundry scan
  → Running security scans...
  → OPA compliance checks passed
  → Trivy scan completed
  → Security scans completed!

CIS 4.1

Non-root user

Enforces that the container runs as a non-root user, following Docker security best practices.

CIS 4.6

HEALTHCHECK required

Ensures all images include a HEALTHCHECK instruction for container orchestrators.

NIST

No secrets in env

Scans environment variables for passwords, tokens, and API keys that shouldn't be baked into images.

OCI

Required labels

Validates that all images carry OCI-compliant metadata labels (title, version, source, etc.).

CIS

No privileged mode

Prevents containers from running in privileged mode or with dangerous Linux capabilities.

NIST

Read-only rootfs

Recommends read-only root filesystem to prevent runtime container tampering.
